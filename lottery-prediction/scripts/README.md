# 双色球预测模型研究报告

## 数据概况
- 数据来源: 2003-2025年双色球开奖数据
- 总期数: 3296 期
- 训练集: 2802 期 (早期85%, 2003年~2022年)
- 测试集: 494 期 (近期15%, 2022年~2025年)

## 模型体系

| 模型 | 架构 | 红球命中 | vs 随机基准 |
|------|------|---------|------------|
| Transformer | 2层Transformer + 特征融合 | 1.0554/6 | -3.3% |
| Deep MLP | 4层全连接 (768→512→256→128) | 1.0801/6 | -1.0% |
| 随机基准 | 理论值 | 1.0909/6 | - |

## 特征工程 (237维)
1. 多窗口频率 (5/10/20/50期)
2. 遗漏期数
3. 趋势特征 (近5期 vs 近20期频率差)
4. 统计特征 (奇偶比/大小比/和值/跨度/连号率)
5. 蓝球频率 + 遗漏
6. 时序序列 (近10期 one-hot)

## Loss 函数
- BCE + Focal Loss (解决类别不平衡)
- Count约束 (预测数量接近6)
- Rank排序 Loss (Top6排序优化)

## 训练结果
- 训练设备: NVIDIA L20 GPU
- 训练轮次: 150 epochs x 2模型
- Loss下降: 3.07 → 0.97 (Transformer), 2.96 → 0.86 (MLP)

## 最终预测 (基于2025年最新数据)
- 🔴 红球: 4, 6, 8, 9, 11, 16
- 🔵 蓝球: 16

## 结论
经过多轮优化，模型命中率仍与随机基准一致（甚至略低），进一步证实彩票为独立随机事件。
